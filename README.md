# Jedi Clip

유튜브 영상과 내 영상으로 숏폼을 만들고, 화면을 녹화하고, 영상을 만드는 Windows 프로그램입니다.

이 저장소는 **설치 파일 배포용**입니다. 소스 코드는 없습니다.

- 설치 파일: [Releases](https://github.com/jedidot/jedi-clip/releases/latest)에서 `JediClip-Setup-v<버전>.exe`
- 한 번 설치하면 새 버전은 앱이 알아서 받아 두고, 앱을 닫을 때 적용합니다.
- 업데이트 정보(`latest.json`)는 서명되어 있어, 앱은 서명이 맞는 설치 파일만 설치합니다.

본인이 권리를 가졌거나 허락받은 영상만 다운로드·재가공하세요.
